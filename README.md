# 🇮🇳 Pathukkalam

### A Modern Social Media Platform Built for India

Pathukkalam is a modern social media platform designed to provide users with a simple, engaging, and mobile-first way to connect, share content, discover people, and interact with their community.

The platform is developed as a **Progressive Web App (PWA)**, allowing users to access it directly through a web browser while providing an app-like experience on mobile and desktop devices.

---

## 🚀 About Pathukkalam

Pathukkalam brings essential social-media features together in one platform.

Users can:

- Create an account
- Login securely
- Create posts
- Upload photos
- Upload videos / reels
- Share documents
- Like posts
- Comment on posts
- Follow other users
- Unfollow users
- View followers and following
- Share posts
- View post engagement
- View user profiles
- Edit profile information
- Update profile photos
- Update cover photos
- Edit profile bio
- Explore content
- Receive notifications
- Install the platform as a PWA

The goal is to build a scalable social platform with a clean, simple, mobile-first user experience.

# 📱 Progressive Web App

Pathukkalam is built as a **Progressive Web App (PWA)**.

This allows users to:

- Open Pathukkalam from a browser
- Install it on supported devices
- Use an app-like interface
- Access it from mobile and desktop
- Avoid requiring a traditional native mobile application for basic access

The PWA approach helps reduce installation barriers and makes the platform accessible across multiple devices.
